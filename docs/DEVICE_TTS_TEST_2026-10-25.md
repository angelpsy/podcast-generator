## Реальные проверки

- Сохранение через MediaStore в `Podcasts/PodcastGenerator/` прошло; конечный MIME `audio/mp4`, один AAC-LC канал, 44100 Hz.
- «Открыть в другом приложении» → системный chooser → AIMP. Android показал PLAYING для URI созданного файла. **Пользователь подтвердил: «Речь слышна и понятна».** Разрешения на всю аудиобиблиотеку, изображения и уведомления AIMP в рамках теста не выдавались; использовано право чтения конкретного URI.
- Независимый разбор на Mac: `afinfo` определил AAC mono, 96004 bit/s, 46.090 с, 1987 пакетов. `afconvert` полностью декодировал M4A в PCM; данные ненулевые.
- В файле Media3 есть резерв `free` около 375 KiB перед аудиоданными. Поэтому общий размер около 932 KiB при полезных AAC-данных около 541 KiB. Оптимизация контейнера пока не выполнялась.
- Внутренний ExoPlayer дошёл до конца 46.1 с. Повторное воспроизведение → Home → возврат: на экране «Слушать», позиция 2.0 с, автоматического продолжения нет.
- Новый полный выпуск заменил предыдущий: после успешного сохранения в папке остался один M4A, `cleanupPending=false`.
- Сбой проверки M4A не потребовал заново запускать TTS. Сохранённый WAV пережил перезапуск процесса и обновление APK; повтор начинался непосредственно с Encoding.
- Новая генерация 02:06:52 → Home примерно через 2 секунды → `cancelled` 02:07:22. Последний M4A не изменился: SHA-256 до и после отмены `635468f328237128c72fc3261afb789191c9cf50a1531fb72bda8b22f36f7fae`, в папке остался один файл. Отмена кооперативная: в этой фоновой пробе заняла примерно 27 секунд после Home. Мгновенное прерывание native inference не реализовано.
- После force-stop и холодного запуска экран восстановил «Аудиофайл сохранён», имя последнего файла и длительность 46.1 с. SIWC-экран показал «Подключено», «Подписка: разрешена»; новый вход и AI-запрос для этой проверки не выполнялись. Приложение возвращено на экран озвучки.

Последний файл на Pixel: `Podcasts/PodcastGenerator/podcast-1792879528574-223f2662.m4a`, 953 709 байт. Копия для проверки на Mac: `.tooling/tts/latest.m4a` (игнорируется Git).

## Встреченные ошибки

1. **TTS-01:** Kotlin indy lambda не имела typed метода, который ищет sherpa JNI. Первый запуск завершился native SIGABRT. Исправлено именованным `@Keep SherpaAudioCallback`; точная сигнатура и отмена покрыты тестами, native-запуск после исправления прошёл.
2. **TTS-02:** `sampleTime >= 0` ошибочно отклонял корректный AAC с priming PTS −36281 мкс. Проверка заменена чтением первого пакета; он содержит 278 байт. После исправления M4A сохранён и воспроизведён.

Подробности: [журнал ошибок](SIWC_ERROR_LOG.md). Полные системные логи и идентификатор USB-устройства в репозиторий не включаются.

## Границы проверки

Это фиксированный русский текст, один голос и одно устройство. Ещё не подключены ввод темы и генерация текста OpenAI, не проведены сравнение голосов, пятицикловый тест нагрева/памяти, тесты нехватки места и убийства процесса в каждой точке публикации. Recovery/cleanup при таких сбоях частично покрыты JVM-проверками. Автономность от сети следует из локального пути assets → TTS → encoder; отдельный запуск в авиарежиме в этом тесте не проводился.
